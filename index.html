Revision: common mistakes

Missing END

Forgetting END IF, END LOOP, END WHILE or END REPEAT is the most common syntax error.

Missing DO

A WHILE loop needs DO: WHILE i <= 5 DO.

No counter update

If you never run SET i = i + 1, the loop may never end.

WHILE vs REPEAT

WHILE continues while the condition is TRUE. REPEAT stops when UNTIL is TRUE.

ELSEIF order

The first TRUE branch runs. Put the highest range first, or 80 marks will match the Pass branch.

Forgot CALL

Creating a procedure does not run it. Use CALL procedure_name();.

Final rule: decision statements choose what happens. Loops repeat work. LEAVE exits; ITERATE skips to the next iteration.
